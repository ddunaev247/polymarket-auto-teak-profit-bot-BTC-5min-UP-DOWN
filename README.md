# Polymarket Auto-Take-Profit (ATP) Bot 🤖📈

Бот предназначен для автоматического отслеживания ваших сделок на рынках **Polymarket** (включая краткосрочные рынки Bitcoin). 
Как только вы покупаете долю (через сайт или сторонний скрипт), этот бот моментально это фиксирует (каждые 5 секунд) и за доли секунды выставляет **лимитный ордер на продажу** этой же доли с заложенным заранее % профита.

## Особенности
✅ **Автоматический трекинг:** Работает в фоновом режиме, проверяя историю сделок каждые 5 сек.  
✅ **Zero-Gas:** Использование `pyclob` (CLOB API) для размещения лимиток `Maker` без необходимости платить газ(L2 Signature).  
✅ **Верификация ордеров:** После размещения ордера бот посылает HTTP запрос к книге заявок Polymarket, чтобы убедиться, что ордер статус `LIVE` (активен).  

## Установка

1. **Убедитесь, что установлен Python 3.9+**
2. Клонируйте/Перейдите в папку с ботом
3. Установите необходимые библиотеки (используется официальный клиент Polymarket):
   ```bash
   pip install -r requirements.txt
   ```
4. Настройте ключи доступа:
   - Переименуйте `.env.example` в `.env`
   - Откройте `.env` и впишите туда `PRIVATE_KEY` и ваш `FUNDER_ADDRESS`.
   - Впишите `PROFIT_MULTIPLIER` (например `1.15` означает, что лимитка будет выставлена на 15% дороже вашей цены покупки).

## Как запустить

В консоли внутри папки введите:
```bash
python bot.py
```

### Как это работает "под капотом"?
1. Скрипт использует метод `client.get_trades()` каждые `CHECK_INTERVAL_SEC` секунд, чтобы найти ваши последние сделки.
2. Как только он находит ордер типа `BUY`, он добавляет его ID в базу, чтобы не срабатывать на него дважды.
3. Умножает цену покупки на ваш `PROFIT_MULTIPLIER` и округляет до `$0.01` (специфика Polymarket Tick Size).
4. Ограничивает верхнюю границу тейка на $0.99 (так как $1.00 — это финальная экспирация).
5. С помощью `client.create_and_post_order()` формирует EIP-712 подпись и бесплатно кидает ее в CLOB Engine Polymarket.
6. Выжидает 0.5 сек и делает запрос статуса вашего ордера, убеждаясь, что биржа его приняла (LIVE).
